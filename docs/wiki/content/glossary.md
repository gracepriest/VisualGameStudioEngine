## Products and binaries

| Term | Meaning |
|---|---|
| **BasicLang** | The language, and `BasicLang.exe` — compiler, language server and debug adapter in one binary |
| **Visual Game Studio** | The Avalonia IDE; `VisualGameStudio.Shell` is its project, `VisualGameStudio.exe` its binary |
| **The engine** | `VisualGameStudioEngine.dll`, the Raylib-backed 2D engine with a C ABI |
| **RaylibWrapper** | `RaylibWrapper.vb`, the VB.NET P/Invoke bindings to the engine |
| **`IDE/`** | A hand-committed xcopy drop of built binaries — convenient and prone to going stale |

## File formats

| Extension | What it is |
|---|---|
| `.bas` | BasicLang source. The resolver also accepts `.bl`, `.basic`, `.mod`, `.cls`, `.class` — `.cls`/`.class` are class files, and `.mod`/`.cls`/`.class` are library units that cannot hold `Main` |
| `.bli` | BasicLang interface/declaration file — e.g. `dom-core.bli` |
| `.blproj` | A BasicLang project (XML) |
| `.blsln` | A BasicLang solution |
| `.vcxproj` | The engine's MSBuild project |
| `.vsix` / `.vstemplate` / `.vstman` | VS extension package, template, template manifest |
| `.xshd` | AvaloniaEdit syntax-highlighting definition |

## Compiler terms

| Term | Meaning |
|---|---|
| **Pipeline** | preprocess → lex → parse → semantic → IR → optimize → backend |
| **IR** | The intermediate representation every backend consumes; built by `IRBuilder`, nodes in `IRNodes` |
| **CFG** | Control-flow graph, per routine; backends reconstruct source-level control flow from it |
| **Backend** | A code generator for one target: C#, C++, JavaScript, LLVM, MSIL |
| **Capability checker** | A per-backend gate that rejects constructs it cannot lower — `BL6xxx` for C++, `BL7xxx` for JS |
| **StdLib shim** | Per-backend mapping of BasicLang's built-in surface onto the target's |
| **blnet** | The .NET interop layer for native C++ projects — type discovery in `BasicLang/Net/`, emission in `BasicLang/Compiler/CodeGen/Net/`. It generates `blnet_proxies.g.hpp`, `blnet_bindings.g.hpp` and `blnet_facade.g.hpp` beside the generated C++ |
| **`<NetProxy>`** | A `.blproj` item declaring one .NET type whose members a native project may call. Nothing is included by default — see [.NET interop](#/net-interop) |
| **Facade** | `blnet_facade.g.hpp` — an ergonomic C++ rendering of the same slots the proxy table exposes under mangled names. `BL6027` warns per colliding C++ name; members the surface collector drops (`BL6026`) never reach it |
| **`BLxxxx`** | A structured diagnostic code; the first digit is the phase — see [Diagnostics](#/diagnostics) |
| **Extern Class** | A type declaration that emits nothing because the runtime already provides it (the JavaScript DOM) |
| **Passthrough** | Unchecked access to the target language — `#CppInclude` + `::` types, or an inline block: `csharp{ }`, `cpp{ }`, `llvm{ }`, `msil{ }`, `javascript{ }` (all five are contextual keywords, so `Dim javascript As Integer` still parses) |

## Tooling protocols

| Term | Meaning |
|---|---|
| **LSP** | Language Server Protocol — completion, hover, diagnostics, navigation |
| **DAP** | Debug Adapter Protocol — breakpoints, stepping, inspection |
| **clangd** | The C++ language server; downloaded on demand |
| **lldb-dap** | The native debug adapter; downloaded on demand |
| **`compile_commands.json`** | The compilation database clangd needs to know each file's flags |
| **CPS** | Common Project System — the Visual Studio 2022 project-system framework the VSIX uses |
| **pkgdef** | The VS registry-fragment file that registers a package's menus, factories and templates |
| **Open VSX** | The extension marketplace the IDE's extension host queries |
| **REPL** | `basiclang --repl` / `-i` — the interactive mode, which runs the full pipeline and executes through the IR interpreter |
| **`ilasm`** | The IL assembler. The MSIL backend writes `.il` text and stops; `ilasm` turns it into an assembly. Located, not required — a machine without one skips the MSIL fixtures |

## .NET interop terms

| Term | Meaning |
|---|---|
| **blnet** | The second stable C ABI, separate from the engine's, that lets a native project reach .NET. Seven pinned core exports (`blnet_abi_version`, `blnet_initialize`, `blnet_addref`, `blnet_release`, `blnet_alloc`, `blnet_free`, `blnet_last_error`) behind a version handshake; an eighth is an ABI change |
| **`<NetProxy>`** | A `.blproj` item declaring a .NET type a native project uses — `<NetProxy Include="System.Console" />`. Its public surface is collected and emitted as proxy slots |
| **The shim** | The per-project managed half, generated by `NetShimGenerator.cs` and published Native-AOT (`PublishAot=true`, `NativeLib=Shared`) into a native DLL deployed beside the executable |
| **The facade** | `blnet_facade.g.hpp` — an ergonomic C++ rendering of the mangled proxy slots under `BasicLang::netfx`, so C++ writes `System::Console::WriteLine("hi")` instead of naming a slot whose signature hash moves |
| **Slot** | One callable member on the proxy table, named by a mangled identifier (declaring type + member + static-ness + generic arity + ref-kinds + a SHA-256 signature hash) |
| **`NetRef`** | The opaque handle a .NET object crosses the boundary as when it has no wire form of its own |

## Engine terms

| Term | Meaning |
|---|---|
| **Framework layer** | The immediate-mode API: initialise, poll, draw, shut down |
| **Engine layer** | The retained API on top: ECS, scenes, and the gameplay subsystems. A documentation split only — all 2,913 exports are named `Framework_…`, the retained ones under a subsystem prefix such as `Framework_Ecs_` |
| **ECS** | Entity-component-system — integer entity handles plus eleven built-in components (`ComponentType` IDs 1-11 in `framework.h`, Transform2D through ParticleEmitter) |
| **Handle** | An `int` identifying an engine-owned object; the only thing that crosses the ABI for most types |
| **C ABI** | `extern "C"` + plain C types — the contract that lets four languages call the engine. The calling convention is asserted only on the managed side (`CallingConvention.Cdecl` on every `<DllImport>`); the header never states one |
| **Introspection** | Runtime component field read/write by entity + component type + field index |
| **ABI-safe struct** | A POD (`Transform2DData`, `Velocity2DData`, `BoxCollider2DData`) declared in `framework.h` as a by-value-safe shape. No export currently takes or returns one — component introspection crosses as scalars through `Framework_Component_GetField*` / `SetField*` |

## Repository conventions

| Term | Meaning |
|---|---|
| **`CLAUDE.md`** | The operating guide — conventions and invariants; explicitly *not* a changelog |
| **`docs/HANDOFF.md`** | A dated state snapshot for a fresh checkout: gates, traps, open work |
| **`docs/superpowers/plans/`** | Implementation plans |
| **`docs/superpowers/specs/`** | Design specs and rationale |
| **Baseline failure** | A known-failing test that is not caused by your change |
| **Fast subset** | `--filter "TestCategory!=Integration"` — ~2 minutes, and not a gate for codegen work |
| **P2a / P2a-2** | The workstream giving native projects access to .NET types — <span class="pill ok">Complete</span>, merged in `77e415b`, Tasks 1-15 done; see [.NET interop](#/net-interop) |
